# Ayudantia1-Git

Actividad de Git y JavaScript - Ayudantía 1, Ingeniería de Software.

Generador de consejos aleatorios. Al hacer clic en el botón, consume la API de [adviceslip.com](https://api.adviceslip.com/advice) y muestra un consejo en pantalla.

- JavaScript
